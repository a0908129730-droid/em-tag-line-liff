LINE 直接傳圖測試

已填入 LIFF ID。此版本使用 Netlify Function 接收 PNG 與預覽圖，並以 HTTPS 網址提供 LINE 讀取。需將整個專案部署（包含 netlify/functions），單獨上傳 HTML 不會部署後端。按下傳送按鈕不會下載檔案。

檔案與輸出

「儲存設計」會下載可再次編輯的 JSON 專案檔。「傳送雷雕 PNG 至 LINE 客服」測試流程：需先設定 LIFF ID 與圖片上傳 API，並從 LINE 聊天室內的 LIFF 入口開啟。設定完成後，程式會在背景產生 PNG、上傳至暫存服務，再將圖片訊息傳回目前 LINE 聊天室，不會自動下載到使用者裝置。
